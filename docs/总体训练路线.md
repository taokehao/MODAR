

## 总体训练路线

我建议完整路线是：

```text
Stage 1: 多模态监督预训练
Stage 2: 结构解析 SFT
Stage 3: 物理一致性 RL / reward-guided fine-tuning
Stage 4: Agent 实验解析工作流
```

## Stage 1: 多模态监督预训练

训练数据来自：

```text
MP + WBM + Alexandria + AFLOW + OQMD
```

每条数据有：

```text
structure
PXRD
neutron diffraction
XRF mass%
XPS-valence
element set
formula ratio
properties
```

训练目标是：

```text
conditions -> crystal structure
```

其中条件组合随机 dropout：

```text
PXRD only
PXRD + element set
PXRD + XRF
PXRD + neutron
PXRD + neutron + XRF
PXRD + neutron + XRF + XPS-valence
PXRD + exact formula
lattice + conditions
conditions without lattice
```

这一阶段让模型学会基本结构先验和多模态输入映射。

## Stage 2: 结构解析 SFT

SFT 不是普通预训练，而是把任务变成“实验解析格式”。

输入可以设计成：

```text
PXRD / neutron / XRF / XPS-valence
known or unknown lattice
candidate hints
noise/background/incomplete peaks
```

输出是：

```text
candidate structure
confidence
match score
explanation tokens / structured metadata
```

更实际一点，SFT 样本可以构造为：

```text
Input:
  noisy PXRD + XRF mass% + optional neutron + valence
  task: solve crystal structure

Target:
  CIF / structure tokens
```

也可以加入“修正任务”：

```text
Input:
  initial candidate + observed spectra
Target:
  corrected structure
```

这个阶段让模型从“会生成结构”变成“会执行结构解析任务”。

## Stage 3: RL / Reward-Guided Fine-Tuning

这里的 reward 应该是多项物理一致性，而不是只看稳定性。

推荐 reward：

```text
R_total =
  w1 * R_pxrd
+ w2 * R_neutron
+ w3 * R_xrf
+ w4 * R_xps_valence
+ w5 * R_structure_validity
+ w6 * R_charge_balance
+ w7 * R_stability
+ w8 * R_diversity
```

各项含义：

```text
R_pxrd:
  回算 PXRD 与输入 PXRD 的匹配度

R_neutron:
  回算 neutron pattern 与输入 neutron 的匹配度

R_xrf:
  生成结构元素质量百分比与 XRF mass% 的一致性

R_xps_valence:
  生成结构可分配价态与 XPS-derived valence 的一致性

R_structure_validity:
  原子距离、晶胞体积、几何合法性

R_charge_balance:
  氧化态/价态组合是否电荷平衡

R_stability:
  formation energy / e_above_hull / external potential predictor

R_diversity:
  防止所有候选坍缩为同一个结构
```

所以稳定性是：

```text
R_stability
```

但它不是核心。核心应该是：

```text
R_pxrd + R_neutron + R_xrf + R_xps_valence
```

因为这才对应“结构解析”。

## RL 怎么具体做

不一定一开始就上复杂 RL。可以分三档：

### 方案 A: Reranking

最稳，最容易发论文。

模型一次生成 `N` 个结构：

```text
candidate_1 ... candidate_N
```

然后用 reward 排序：

```text
score(candidate_i)
```

输出 top-k。

这不改变模型参数，但能显著提升结果。

### 方案 B: Reward-Weighted SFT

用模型生成候选，计算 reward，然后把高 reward 样本作为新的训练数据继续 SFT。

```text
generate -> score -> select high reward -> fine-tune
```

实现简单，稳定性好。

### 方案 C: 真 RL Fine-Tuning

例如 policy gradient / PPO / DPO-like / GRPO-like。

```text
policy generates structure
reward model scores structure
policy updated toward high-reward samples
```

这个创新性更高，但风险也更大，建议放在后期。

我建议论文主线采用：

```text
Reranking + reward-weighted fine-tuning
```

这样既有 RL 思想，又更稳。

## Agent 工作流

最终 Agent 面向实验人员使用，流程可以是：

```text
1. 输入实验数据
   PXRD / neutron / XRF / XPS / known lattice

2. 数据预处理
   背景扣除
   峰位识别
   谱图归一化
   噪声估计
   XRF mass% 归一化
   XPS valence 提取

3. 判断任务模式
   known-cell:
     已有 lattice，执行辅助结构解析
   unknown-cell:
     无 lattice，执行端到端结构解析
   partial:
     缺少 neutron 或 XPS 时自动降级

4. 候选结构生成
   调用多模态生成模型
   生成 top-N candidates

5. 物理一致性打分
   回算 PXRD
   回算 neutron
   计算 XRF 一致性
   计算 XPS-valence 一致性
   检查结构合法性
   检查 charge balance
   调用 stability predictor

6. 候选排序
   按 total reward 排序
   聚类去重
   输出 top-k

7. 可选精修
   对 top-k 结构做 Rietveld / Le Bail / geometry relaxation
   更新谱图匹配分数

8. 解释与报告
   给实验人员输出：
     候选 CIF
     谱图匹配图
     元素组成一致性
     价态一致性
     稳定性分数
     可能杂相或表面氧化提示
     下一步实验建议
```

## 实验人员如何用

实验人员可以选择输入等级：

```text
最低输入:
  PXRD

常规输入:
  PXRD + XRF

更强输入:
  PXRD + neutron + XRF

完整输入:
  PXRD + neutron + XRF + XPS-valence

如果已完成 indexing:
  additionally provide lattice
```

系统输出：

```text
ranked CIF candidates
confidence score
PXRD/neutron fit score
composition consistency
valence consistency
stability assessment
next experiment suggestion
```

## 最推荐的论文叙事

我建议这样写：

**We develop a physics-rewarded multimodal crystallographic agent that combines generative structure solving with X-ray, neutron, composition, and valence consistency rewards.**

中文就是：

**构建一个物理 reward 约束的多模态晶体结构解析 Agent，将结构生成、谱图回算、组成/价态一致性和稳定性筛选统一到实验解析流程中。**

这个比“用稳定性强化学习生成材料”更贴近我们的目标，也更符合 X-ray/neutron AI Collection。
